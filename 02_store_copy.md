# Store copy package

Replace every default Shopify text block with the copy below. I've written it niche-agnostic with `[BRAND]` placeholders — find/replace once you pick a brand name.

> **Where to paste each piece:** Shopify Admin → Online Store → Themes → Customize. Each section is editable inline.

---

## 1. Top announcement bar

Currently says: "Welcome to our store" — generic, wastes prime real estate.

**Replace with one of these:**

- `Free shipping on orders over $50 → ✦ 30-day returns`
- `New arrivals dropping weekly · Free US shipping over $50`
- `🚚 Free shipping over $50 · ↩ Free returns within 30 days`

The announcement bar should communicate **value** (shipping/returns) not greet people. Free shipping thresholds are conversion gold — they push average order value up.

---

## 2. Hero section (replace the mountain illustration + "Browse our latest products")

### Headline options (pick one)

- `[Product category] you'll actually use.` *(e.g., "Gear you'll actually use.")*
- `Curated finds for everyday life.`
- `The internet's best [category], in one place.`
- `Things worth keeping.`
- `Everyday upgrades. No fluff.`

### Subheadline options

- `Hand-picked products, fast US shipping, and a 30-day returns guarantee.`
- `We test, we curate, we ship. You enjoy.`
- `Quality finds at fair prices, delivered to your door.`

### Primary button

- `Shop bestsellers` (better than the default "Shop all" — implies social proof)
- `Shop the collection`

### Hero image

**Critical:** the default mountain illustration MUST go. It's the #1 "this is a fake store" tell. Options ranked by ease:

1. **Free, fastest:** Use a product flat-lay you photograph yourself with a phone on a clean surface in natural light
2. **Free, slower:** Pull a clean lifestyle image from Unsplash (search your category) — make sure it doesn't look like generic stock
3. **$0–10:** Use Canva to make a clean text-over-color hero
4. **Best:** A short looping video of your product in use (huge conversion lift)

## 3. About page

Customers check this page to verify you're a real human. Empty or generic = bounce.

```
About [BRAND]

Hi — I'm Charles, the person behind [BRAND].

I started this shop because I was tired of scrolling through endless
junk on big marketplaces trying to find products that were actually
worth buying. So I started my own collection: a small, hand-picked
catalog of things I'd genuinely use myself, sourced from suppliers
I trust, and shipped to you with care.

Every product here meets three rules:
  1. It has to solve a real problem or actually feel good to use
  2. It has to be priced fairly — no hidden markups
  3. I have to be willing to use it myself

If you ever have a question, an issue, or just want to say hi —
the contact form below goes straight to my inbox. I read every message.

Thanks for being here.

— Charles
[BRAND]
```

> **Why this works:** Real founder name, plain language, specific (not corporate), invites contact. This is the single highest-ROI page on a small store.

[contact form embed]

## Where these go in Shopify

| Copy block | Location |
|---|---|
| Announcement bar | Customize → Header → Announcement bar |
| Hero headline/sub/button | Customize → Home page → Image banner / Hero |
| About page | Online Store → Pages → Add page → "About" |
| Contact page | Online Store → Pages → Add page → "Contact" (use template "page.contact") |
| Footer | Customize → Footer → Text block |
| Collection intro | Products → Collections → [Collection] → Description |
| Empty cart | Customize → Cart → Empty cart text |

Most of these are 30-second copy/paste edits.
